# 泌尿外科科普短文规范与模板

面向患者及家属，兼顾低年资医生阅读。以医学准确为基础，让读者看懂、记住，并能采取适合自己的行动。

## 一、写作原则

每篇文章先回答三个问题：

1. 患者最值得带回家的一句话是什么？
2. 患者读完后，可以做什么？
3. 哪些情况需要进一步检查或寻求医生帮助？

内容围绕这些问题取舍。短文不追求覆盖全部知识，必要的专业细节可以放在延伸阅读中。

## 二、内容制作要点

| 写作环节 | 具体做法 |
|---|---|
| 确定主题 | 聚焦一个主要问题，先写出患者应记住的核心信息，再取标题。 |
| 拟定标题 | 体现文章对读者的价值，具体、自然、准确。避免空泛标题、夸大效果和制造焦虑。 |
| 起始铺垫 | 简短说明问题为什么与患者有关，在开头呈现核心信息，避免长篇背景。 |
| 组织正文 | 按患者关心的问题分段。小标题准确对应下文，同级标题保持相近结构，避免写成综述目录。 |
| 给出建议 | 讲清谁适合、为什么做、怎样做，以及何时需要医生帮助。避免只有“多喝水、注意饮食”等笼统表述。 |
| 解释术语 | 必要术语第一次出现时就解释。少用缩写，不要求患者理解完整的生化机制。 |
| 表达证据 | 区分指南建议、观察性研究和临床试验；不把关联写成因果，不把短期指标改善写成长期疗效。 |
| 使用数字 | 只保留帮助理解或行动的数字，说明单位、适用人群和含义。避免把研究人群比例直接当作个人风险。 |
| 说明适用范围 | 一般建议与个体方案分开表述，交代需要调整的情况，避免统一饮食、饮水或补充剂方案。 |
| 收束全文 | 简短重申核心信息和下一步行动，不机械重复全部正文。 |
| 参考资料 | 一般保留3—4条关键资料，优先指南、共识和直接相关研究，保证来源可核查。 |
| 摘要介绍 | 控制在100字以内，说明为什么值得读、文章能帮助解决什么问题，与正文结论保持一致。 |

## 三、适当融入代谢评估与个体化检查

当检查结果会影响预防或治疗选择时，应自然融入正文。

### 适合融入的内容

结石复发预防、饮食调整、饮水目标、钙与维生素补充，以及结石合并骨量异常等主题，可结合需要说明结石成分分析、血液检查或24小时尿液代谢检测的价值。

其他泌尿外科主题，应选择与其相关的检查，不机械套用结石代谢评估。

### 检查介绍应回答的问题

- **为什么查：**检查能帮助寻找什么原因？
- **谁需要查：**哪些患者值得与医生讨论？
- **怎样准备：**是否需要保持通常饮食、规范留样或遵循其他要求？
- **结果怎样用：**检查如何帮助调整饮食、治疗或随访？

篇幅有限时，优先讲清“为什么查”和“结果怎样用”。

### 表述边界

- 不暗示所有患者都必须完成全套检查。
- 不把一次异常结果直接等同于确诊。
- 不把24小时尿液检测写成普通尿常规。
- 不让患者凭单个指标自行用药、停药或严格忌口。
- 涉及医院服务时，核实项目及流程，建议就诊前咨询。

### 必要时融入多学科评估

复杂或反复结石、明显代谢异常、肾功能下降、胃肠疾病或骨健康问题等，可说明联合相关专科的价值。

交代“多学科帮助解决什么问题”，不将多学科门诊作为每篇文章的固定环节。

## 四、沿用DASH文章的视觉风格

整体保持轻快、舒适、克制，以阅读清晰为优先。

| 元素 | 建议样式 |
|---|---|
| 主标题 | 深蓝，醒目，避免过长 |
| 副标题 | 青绿色，补充文章角度，可少量使用斜体 |
| 主要小标题 | 深蓝、加粗，划分主要内容 |
| 次级小标题 | 蓝色或青绿色，与正文有清楚区别 |
| 正文 | 深灰，段落简短，行距舒适 |
| 核心信息 | 少量加粗或青绿色强调，避免整段反复强调 |
| 补充说明 | 可用少量灰色斜体，但必须保持可读性 |
| 参考资料 | 较小字号，颜色清晰，保留可点击链接 |
| 配图 | 柔和、简洁，支持核心信息，避免强烈的器官写实细节 |

Word可参考正文11磅、1.35倍行距、段后7磅，并根据篇幅调整。公众号发布时需检查手机端效果，避免照搬纸张分页。

重要的适用条件和安全提示，应清楚呈现，不仅靠浅灰色或斜体表达。颜色不是唯一的层次标记，还应配合字号、加粗和留白。

## 五、配图原则

- 一张图围绕一个主要信息，与标题和正文一致。
- 图中文字简短，缩小后仍能辨认。
- 器官插画可适度简化、卡通化，兼顾舒适感与辨识度。
- 箭头、位置和颜色不能暗示未经证实的因果关系。
- 示意图不作为诊断依据；AI生成图注明“AI生成示意图”。
- 发布前检查文字、解剖关系、裁切和医学含义。

## 六、短文模板

### 标题
突出患者最关心的问题或最值得记住的信息。

### 副标题
补充文章角度，不重复标题。

### 开头
用常见疑问或简短背景说明为什么要了解这个问题，尽早给出核心信息。

### 为什么会出现这个问题？
解释理解行动建议所必需的原因或机制。

### 怎样判断是否与自己有关？
说明适用人群，必要时融入检查或代谢评估。

### 日常可以怎样做？
给出具体、可执行的建议，并交代适用条件。

### 哪些情况需要进一步诊治？
说明仅靠日常管理不足的情况，必要时介绍专科或多学科评估。

### 简短结尾
重申核心信息和下一步行动。

### 参考资料
列出3—4条关键来源。

模板按主题取舍，不要求每篇都包含全部栏目。

## 七、发布前审核

### 医学准确性

核对来源、适用人群、数字和治疗表述；检查是否混淆关联与因果、研究结果与临床建议。

### 患者易读性

检查标题是否有价值、开头是否清楚、小标题是否对应内容、术语是否解释、建议是否可执行。

### 视觉与使用效果

检查字号、对比度、留白、分页或手机端显示，以及图片是否支持正文。条件允许时，请患者试读并反馈：

“你记住了什么？准备做什么？哪里没看懂？”

参考CDC清晰传播评估指南审核传播质量，同时独立完成医学核实。评分不能替代真实读者反馈，也不代表医学结论正确。
